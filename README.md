# 🎓 Assignment Portfolio Website  

**👩‍💻 Author:** *Faiza Khan*  

---

## 🖥️ About the Project  
A **minimalist portfolio website** built to showcase completed coursework and projects with a clean, interactive design.  

✨ **Key Features:**  
- ⌨️ Typing animation using CSS `@keyframes`  
- 📜 Scrollable assignments list for easy navigation  
- 🔗 Clickable links to Azure-hosted pages  
- 🌄 Subtle background image for aesthetic appeal  

---

## 🧰 Tech Stack  
| Technology | Purpose |
|-------------|----------|
| 🧩 **HTML5** | Structure and content layout |
| 🎨 **CSS3** | Styling, animations, and responsive design |
